# Aura 0.7.0-beta.5

**Udkast.** Noterne samles, mens betaen bygges. Intet er udgivet.

## Det, der er nyt under motorhjelmen

- **Motorens nøgler kan ikke længere læses af andre programmer på macOS.** Motorens adgangskode og gatewayens midlertidige nøgle stod i motorens miljø, hvor en kommando, du havde godkendt uden sandkasse, kunne læse dem (fx med `ps eww`). Nu overskriver Aura dem i motorens proces, så snart motoren er startet, og før AI'en kan køre noget. Lykkes det ikke, startes opgaven ikke. Det lukker den kendte begrænsning fra 0.7.0-beta.3.

## Kendt begrænsning

I de første sekunder, mens motoren starter, står nøglerne stadig i dens miljø. På Windows, hvor der ingen sandkasse er, kan et program med dine rettigheder stadig læse dem. Godkend kommandoer uden sandkasse med omtanke.
